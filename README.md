# e-plantShopping

**Paradise Nursery** – a React‑Redux single‑page application that lets users browse houseplants, add them to a shopping cart, and manage their order.

## Repository
- **Name:** `e-plantShopping`
- **URL:** https://github.com/your‑username/e-plantShopping

## Project Description
This project is the capstone for the IBM Skills Network course *Developing Front‑End Apps with React*. It demonstrates:

* A landing page that welcomes users to **Paradise Nursery** with a “Get Started” button.  
* A product listing page that groups houseplants into three categories (Air‑Purifying, Low‑Light, Succulents) with at least six unique plants per category.  
* Full cart functionality powered by Redux: add‑to‑cart, quantity controls, delete, and a checkout placeholder.  
* A responsive navigation bar that appears on both the product list and cart pages.

## How to Run
```bash
git clone https://github.com/your-username/e-plantShopping.git
cd e-plantShopping
npm install
npm start
```

The app will be available at `http://localhost:3000`.
